1️⃣ نصب و راه‌اندازی

گام 1: نصب پایتون
   • نسخه پایتون 3.8 یا بالاتر نصب کنید
   • بررسی نسخه: python --version

گام 2: نصب وابستگی‌ها
   cd /path/to/project
   pip install -r requirements.txt

گام 3: نصب Playwright
   playwright install chromium

گام 4: تنظیم فایل .env
   ایجاد فایل .env در ریشه پروژه:
   
   BOT_TOKEN=توکن_ربات_تلگرام
   ADMIN_ID=آیدی_عددی_ادمین
   CARD_NUMBER=شماره_کارت_برای_پرداخت
   ACCOUNT_NAME=نام_صاحب_حساب

گام 5: اجرای ربات
   python bot.py

3️⃣ نحوه کار با سیستم

🤖 از دید کاربر (تلگرام):

   1. کاربر /start را می‌زند
   2. گزینه "📝 ثبت لایحه" را انتخاب می‌کند
   3. عنوان لایحه را انتخاب می‌کند
   4. روش ردیابی را انتخاب می‌کند (شماره پرونده / شماره بایگانی)
   5. اگر شماره بایگانی:
      • شماره بایگانی را وارد می‌کند
      • روی "🔍 انتخاب شعبه از لیست" کلیک می‌کند
      • از درخت شعب ناوبری می‌کند:
        قوه قضائیه → استان → نوع دادگاه → شعبه
      • شعبه با آیکون ✅ را انتخاب می‌کند
   6. ادامه فرآیند ثبت لایحه

💻 از دید برنامه‌نویس:

   جریان داده:
   
   کاربر انتخاب می‌کند
          ↓
   callback به branches.py ارسال می‌شود
          ↓
   branches.py واحد را از units_compact.json می‌خواند
          ↓
   بررسی می‌کند که آیا واحد کد دارد؟
          ↓
   اگر بله: state را update می‌کند
          ↓
   lavayeh_handlers.py کد شعبه را دریافت می‌کند
          ↓
   ادامه فرآیند با کد معتبر

4️⃣ رفع مشکلات رایج

❌ مشکل: شعب نمایش داده نمی‌شوند

   ✅ راه‌حل:
   1. بررسی وجود فایل units_compact.json
   2. اجرای تست:
      python test_branches_system.py
   3. بررسی لاگ ربات برای خطاها

❌ مشکل: ربات پاسخ نمی‌دهد

   ✅ راه‌حل:
   1. بررسی BOT_TOKEN در .env
   2. اطمینان از اجرای bot.py
   3. بررسی اتصال اینترنت
   4. چک کردن لاگ‌ها

❌ مشکل: خطا در انتخاب شعبه

   ✅ راه‌حل:
   1. بررسی اینکه شعبه کد دارد
   2. فقط شعب با ✅ قابل انتخاب هستند
   3. اجرای مجدد /start

❌ مشکل: خطای No module named 'aiogram'

   ✅ راه‌حل:
   pip install -r requirements.txt

5️⃣ به‌روزرسانی فایل داده

🔄 دریافت فایل کامل:

   روش 1: از API سامانه قضایی
   روش 2: از منبع رسمی دادگستری
   روش 3: درخواست از تیم فنی

📥 نحوه جایگزینی:

   1. فایل جدید را دانلود کنید (all_units.json)
   
   2. اگر حجم زیاد است، فشرده کنید:
      python make_compact_units.py
   
   3. فایل قدیمی را backup بگیرید:
      cp units_compact.json units_compact.json.backup
   
   4. فایل جدید را جایگزین کنید:
      cp units_compact.json.new units_compact.json
   
   5. تست کنید:
      python test_branches_system.py
   
   6. ربات را restart کنید:
      # متوقف کردن
      Ctrl+C
      # راه‌اندازی مجدد
      python bot.py

✅ بررسی صحت فایل:

   فایل باید:
   • فرمت JSON معتبر داشته باشد
   • حداقل 1 ریشه داشته باشد
   • تمامی Id ها یکتا باشند
   • روابط والد-فرزند صحیح باشند
   • شعب نهایی حتماً Code داشته باشند
